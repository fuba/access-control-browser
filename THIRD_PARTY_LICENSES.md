To regenerate this table from the live workspace:

```bash
cargo metadata --format-version 1 \
  | jq -r '.packages[] | "\(.license // "(license_file)")|\(.name)"' \
  | sort | uniq -c | sort -nr
```

inside their Cargo source trees; those are not redistributed by us beyond
the crates.io tarball that `cargo` already obeys.

## UI dependencies (Node.js, build-time only — not redistributed)

The Next.js UI is statically exported at build time; the npm packages
themselves are **not** redistributed in the runtime Docker image (only
the compiled `ui/out/` bundle is embedded). For completeness:

- **Next.js** — MIT (<https://github.com/vercel/next.js/blob/canary/license.md>)
- **React** / **React DOM** — MIT (<https://github.com/facebook/react/blob/main/LICENSE>)
- TypeScript / type definition packages — Apache-2.0 / MIT

The exported `ui/out/` JavaScript is generated by Next.js's bundler from
our own MIT-licensed sources plus React's MIT-licensed runtime.

## Bundled in the Docker runtime image

The runtime stage of [`Dockerfile`](./Dockerfile) is based on
`debian:bookworm-slim` and installs the following:

| Component | License | Notes |
|---|---|---|
| Debian system libraries (`libnss3`, `libcairo2`, `libgbm1`, etc.) | mostly LGPL / MIT / BSD | Each `/usr/share/doc/<pkg>/copyright` in the image carries the upstream notice. |
| `chromium` (Debian package) | BSD-3-Clause (Chromium core) + many component licenses | Bundled as an unmodified executable; we don't statically link with it. The Debian package's own copyright file remains at `/usr/share/doc/chromium/copyright` inside the image. |
| `fonts-liberation` | OFL-1.1 | <https://github.com/liberationfonts/liberation-fonts/blob/main/LICENSE> |
| `fonts-noto-core` / `fonts-noto-cjk` / `fonts-noto-extra` / `fonts-noto-color-emoji` / `fonts-noto-mono` | OFL-1.1 | <https://github.com/notofonts/notofonts.github.io/blob/main/LICENSE> |
| `tini` | MIT | <https://github.com/krallin/tini/blob/master/LICENSE> |

The OFL-1.1 (SIL Open Font License) permits embedding and redistribution
of font binaries. The reserved-name clause requires that derivative
fonts not use the original names; we do not derive new fonts — we ship
the upstream Noto / Liberation TTF/OTF files unmodified, so no
restriction applies in practice.

The Chromium binary contains many components individually licensed
under MIT, BSD, LGPL-2.1+, and others. Per Debian's packaging,
`chromium`'s combined copyright file lists them at
`/usr/share/doc/chromium/copyright` inside our runtime image; that file
is the canonical aggregated notice.
